# FloatNote 2.2.0 — 快速开始 / Quick start

1. 解压 ZIP 到可写目录，双击 FloatNote.exe。无需编译源码。
2. 鼠标移到便签顶部提示附近，进入设置；右下角拖动调整大小。
3. 向下压缩高度可收纳便签，点击剩下的状态条恢复。
4. Ctrl+Alt+E 找回编辑；Ctrl+Alt+H 显示/隐藏；Ctrl+Alt+P 切换鼠标穿透。
5. 升级前退出旧版，只替换 EXE，保留 data 文件夹；建议先备份 data。
6. 截图或远程看不到便签时，在设置里切换毛玻璃。

便签默认预览 Markdown。点击文字进入原文编辑，点击空白、操作控件或切到其他窗口后自动保存并回到预览；仅暂停打字不会退出编辑。空便签点击文字区域即可输入。
支持标题、粗体、斜体、删除线、有序/无序列表、任务列表、引用、行内代码、围栏代码块和链接文字。链接和任务标记点击后进入编辑。内容仍按 Markdown 原文保存在本地 `data/note.txt`，普通文本照常使用；表格、图片和 HTML 暂按原文显示，不加载远程内容。

Extract the ZIP into a writable folder and run FloatNote.exe. No build step is needed.
Hover near the top hint for settings; resize with the bottom-right grip. Shrink vertically to tuck the note away, and click the remaining bar to restore it.
Ctrl+Alt+E restores editing, Ctrl+Alt+H toggles visibility, and Ctrl+Alt+P toggles click-through. Running the app again also restores the note.
Exit before upgrading, replace the EXE and keep your data folder. Use frosted glass when screenshot/remote visibility is needed.
The new settings panel is currently in Chinese. Binaries are unsigned; checksums are provided on the release page.

Notes start in Markdown preview. Click text to edit its source; click blank space, a control, or another window to save and return to preview. Pausing typing does not leave editing. Click anywhere in an empty note's text area to start writing.
Headings, emphasis, strikethrough, lists, tasks, quotes, inline/fenced code and link labels are supported. Clicking a link or task marker edits its source. Markdown remains in `data/note.txt`; plain text still works. Tables, images and HTML are shown as source, with no remote content loading.
